# Sample Assets

Bạn có thể bỏ các file âm thanh (`.mp3`, `.wav`, `.webm`) mô phỏng cuộc họp vào thư mục này để dễ dàng tải lên qua giao diện Web (nút **Upload Audio**).

File `sample_context.txt` chứa một ví dụ về Context (bối cảnh / bộ từ vựng) mà bạn có thể copy và dán vào ô **Meeting Agenda / Context** trên giao diện để AI nhận diện các thuật ngữ nội bộ chính xác hơn.
